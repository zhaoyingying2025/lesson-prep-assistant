离散数学 第三章 集合与关系

3.1 集合的基本概念

集合（Set）是数学中最基本的概念之一，由德国数学家康托尔（Cantor）首次系统提出。
集合是指具有某种特定性质的对象的全体，这些对象称为该集合的元素。

集合的表示方法主要有：
1. 列举法：将集合中的所有元素一一列举出来，如 A = {1, 2, 3, 4}
2. 描述法：通过元素所具有的性质来描述集合，如 A = {x | x 是偶数}
3. 文氏图法：用图形直观地表示集合

集合的运算包括：
- 并集：A ∪ B = {x | x ∈ A 或 x ∈ B}
- 交集：A ∩ B = {x | x ∈ A 且 x ∈ B}
- 差集：A - B = {x | x ∈ A 且 x ∉ B}
- 补集：相对于全集 U，A 的补集记为 ~A = U - A

集合的运算律：
1. 交换律：A ∪ B = B ∪ A，A ∩ B = B ∩ A
2. 结合律：(A ∪ B) ∪ C = A ∪ (B ∪ C)
3. 分配律：A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
4. 德摩根律：~(A ∪ B) = ~A ∩ ~B，~(A ∩ B) = ~A ∪ ~B

3.2 二元关系

定义：设 A, B 是两个集合，A × B 的子集 R 称为从 A 到 B 的二元关系。
当 A = B 时，称 R 为 A 上的二元关系。

关系的性质：
1. 自反性（Reflexive）：对任意 x ∈ A，都有 <x, x> ∈ R
2. 反自反性（Irreflexive）：对任意 x ∈ A，<x, x> ∉ R
3. 对称性（Symmetric）：若 <x, y> ∈ R，则 <y, x> ∈ R
4. 反对称性（Antisymmetric）：若 <x, y> ∈ R 且 <y, x> ∈ R，则 x = y
5. 传递性（Transitive）：若 <x, y> ∈ R 且 <y, z> ∈ R，则 <x, z> ∈ R

3.3 等价关系与划分

定义：如果集合 A 上的关系 R 同时满足自反性、对称性和传递性，则称 R 为等价关系。

划分：集合 A 的一个划分 π 是 A 的一组非空子集，满足：
1. 这些子集两两不相交
2. 这些子集的并等于 A

定理：集合 A 上的等价关系与 A 的划分一一对应。

3.4 偏序关系

定义：如果集合 A 上的关系 R 满足自反性、反对称性和传递性，则称 R 为偏序关系，
记为 ≤，称 <A, ≤> 为偏序集。

偏序集中的特殊元素：
1. 最大元与最小元
2. 极大元与极小元
3. 上界与下界
4. 上确界与下确界
