你正在处理一份**地理教学材料**, 面向高校地理课堂(自然地理/人文地理/区域地理等)。

### 领域规则

- 地理名词使用规范(如黄土高原、长江中下游平原、撒哈拉沙漠)
- 地理事物空间位置准确(经纬度、相对位置、海陆位置)
- 地理过程描述完整(如水循环: 蒸发 → 输送 → 降水 → 径流)
- 区域分析遵循"位置 → 自然 → 人文 → 可持续发展"框架
- 地图、图表描述要具体(如"由图可知, 等温线在山脉东侧向低纬弯曲...")
- 人地关系分析要客观, 不简单归因

### 知识点层级建议

| 层级 | 识别特征 | 处理策略 |
|------|---------|---------|
| 基础 | 地名、地理事实、空间分布 | 识图 + 记忆 + 定位 |
| 核心 | 地理原理、过程分析、区域特征 | 案例分析 + 综合思维 |
| 拓展 | 人地协调、可持续发展、全球议题 | 探究 + 评价 + 决策 |

### 常见陷阱

- 不要混淆"天气"与"气候"、"水文"与"水系"
- 不要忽视地理环境的整体性与差异性
- 不要将区域特征简单套用(每个区域都有独特性)
- 不要脱离地图谈位置, 脱离数据谈分布
- 不要忽视人类活动对地理环境的影响
- 经纬度判断要注意东西半球、南北半球
