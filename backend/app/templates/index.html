📖 备课助手 · 详细使用教程

1. 新建课程空间

前置条件：打开应用首页。

操作：在左栏「课程空间」标题右侧点击 + 按钮，输入课程名、专业、描述，点击"创建"。

预期：列表中出现新课程并自动高亮，下方章节树、教材区激活。

常见错误：课程名为空 → 无法创建；点击列表不生效 → 先关闭上下文菜单。

2. +新建章，搭建章节结构

前置条件：已有当前课程被选中。

操作：当前课程标题栏右侧点击「+」按钮，或在章节树节点菜单里选择"新增子节/重命名/删除"。

预期：章节树出现新建章/节，支持多层级折叠展开。

常见错误：选中某章后点击+仍建在根 → 注意按钮上下文是课程级"新建章"。

3. 上传教材并预选类型

前置条件：当前课程已激活。

操作：左下"教材资源"区点击↑按钮 → 先选择教材类型（6 类 + 自动识别）→ 拖放或点选文件 → 开始上传。

预期：教材列表中出现对应文件，并显示彩色类型 badge / 大小 / 字数。

常见错误：文件过大或扫描版PDF导致解析失败 → 转 DOCX / OCR 后重传。

4. 一键提取知识点 & 联网校验准确性

前置条件：课程下已上传教材。

操作：当前课程标题栏点击「📖提知」→ 勾选要提取的教材（可多选）→ 确定 → 等待进度完成。

预期：toast 提示新增知识点数，可在弹窗选择"立即导出XLSX"。

常见错误：返回空 → 请检查教材为文字版且不要一次性选择过多。

5. 章节条①：章节级提取知识点

前置条件：已新建章节或填入章节名。

操作：在中间章节输入条填写章节 → 点击"① 提取知识点"。

预期：知识点面板展开，可手动改层级/重点/难点/考点。

常见错误：章节名为空 → 提示先填写章节。

6. 章节条②：选择模板并生成教案

前置条件：知识点面板至少有 1 个知识点。

操作：点击"⚙ 参数"配置课时/风格/作业分层等 → 点击"② 生成教案"。（可在模板库中维护默认模板 JSON）

预期：右侧预览区出现全表格化六阶段教案，教案记录列表同步增加。

常见错误：结构不完整 → 使用失败对话框的"模板填充"或"降参重试"补救。

7. 中间对话框③：对话微调教案细节

前置条件：已生成一份教案。

操作：在底部对话框输入修改意见，如"导入换案例、缩短讲解到30分钟、增加互动"，回车发送。

预期：AI 回显调整并刷新右栏教案预览；可导出 MD/DOCX。

常见错误：发送按钮禁用 → 必须先有 currentLessonId（成功生成过教案）。

8. 生成PPT并导出

前置条件：当前存在已生成教案。

操作：点击"③ 生成PPT" → 选择风格/密度/配图方式 → 生成并导出。

预期：浏览器自动下载 .pptx，左下 PPT 记录列表新增一项。

常见错误：打开显示空白 → 升级 PowerPoint/WPS 或降低密度重生成。

❓ Q&A 常见问题

Q1: LLM未配置或报错怎么办？
A. 点右上角「设置」→ 填入 APIKey + BaseURL + Model → 点"测试连接"确认通过后再操作。
Q2: 教材解析失败（空/乱码）怎么办？
A. 先转 PDF 或另存为 DOCX；扫描件需先 OCR；若仍失败请联系管理员并带上文件名。
Q3: 一键提取知识点返回空？
A. 检查教材是否为文字版（非扫描图片）；或减少一次性勾选的教材数量后重跑。
Q4: 教案生成失败或结构不完整？
A. 在失败对话框选择"重试"或"降参重试"；或点"用模板快速填充"兜底。
Q5: PPT文件打开显示空白或加载失败？
A. 安装高版本 PowerPoint 或 WPS；或在 PPT 导出设置中切换到 Less 密度导出。
Q6: 上传PPT显示加载失败？
A. 检查扩展名为 .pptx 且文件 < 50MB；或选择"重新生成"下载新的副本。
