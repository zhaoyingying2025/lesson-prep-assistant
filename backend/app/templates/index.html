备课助手 · 新手教程

备课全流程概览

① 新建课程 → 新建章节 → 上传教材 → 提取知识点 → 生成教案 → 对话微调 → 生成PPT

模块一：课程与章节管理

  • • 左栏顶部点「+」新建课程，输入课程名称、专业、学科等信息
  • • 点击课程旁的「+」新建章节，章节名称建议与教材目录一致
  • • 点击课程旁的「+」可上传教材文件（支持 PDF、DOCX、TXT）
  • • 左侧课程列表点击可切换课程，所有数据按课程隔离

模块二：知识点提取

  • • 选中章节后，点击章节条上的「①提取知识点」按钮
  • • 系统会自动分析教材内容，提取关键知识点并展示
  • • 点击课程旁的「提知」可一键提取全部章节的知识点
  • • 提取结果会显示在右侧知识点面板，支持勾选和导出

模块三：教案生成与编辑

  • • 提取知识点后，点击「②生成教案」进入教案参数配置
  • • 可设置教案语言风格、详细程度、教学目标等参数
  • • 生成后可在底部对话框输入修改意见，AI会实时调整
  • • 支持多版本历史，可随时回退到任意版本
  • • 预览区"教案预览"标签下可查看所有历史教案文件

模块四：PPT生成与导出

  • • 教案满意后，点击「③生成PPT」选择风格和密度
  • • 支持多种风格：学术简约、青绿水墨、清新卡通、商务正式、极简黑白
  • • 生成后可在预览区"PPT预览"标签下查看所有PPT文件
  • • 支持下载 PPTX 文件，可在 PowerPoint/WPS 中编辑
  • • 教案支持导出为 Markdown 或 DOCX 格式

模块五：模板库使用

  • • 点击右上角「模板库」管理教案模板和PPT模板
  • • 教案模板：下载Word模板后编辑内容，再上传回系统
  • • PPT模板：上传 .pptx 文件，AI自动分析排版特征
  • • 模板可随时切换，系统会自动适配模板样式

模块六：设置与常见问题

  • • 点右上角「设置」填入 LLM API 信息后测试连接
  • • 素材解析：文字版 PDF/DOCX 效果最佳，扫描件需先 OCR
  • • 教案生成不完整：点击失败对话框的"重试"或"降参重试"
  • • 支持切换主题：默认墨绿、暖阳橘棕、护眼米黄、静湖蓝调、墨韵黑白
