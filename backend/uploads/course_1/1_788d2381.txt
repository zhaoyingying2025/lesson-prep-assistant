# 第1章 Python基础

Python是一种广泛使用的高级编程语言，由Guido van Rossum于1991年发布。

## 1.1 变量与数据类型

Python中的变量不需要声明类型，直接赋值即可使用。常见数据类型包括：
- 整数（int）：如 10, -5
- 浮点数（float）：如 3.14
- 字符串（str）：如 "Hello"
- 布尔值（bool）：True 或 False

## 1.2 控制结构

Python支持if-else条件判断和for/while循环。

### if语句示例
if x > 0:
    print("正数")
elif x == 0:
    print("零")
else:
    print("负数")

## 1.3 函数

使用def关键字定义函数：
def add(a, b):
    return a + b

## 本章小结

本章介绍了Python的基础语法，包括变量、数据类型、控制结构和函数定义。掌握这些内容是后续学习的关键。
